# Desktop candidate validation — 2026-11-11

## Purpose and scope

Version 0.2.0 makes the existing authenticated video review desk a full native
application: trusted-owner setup, first administrator, separate staff roles,
identified persistent profiles, owned ephemeral loopback startup and normal Quit.
Arbitrary supported authorized short clips still use the same import, masks,
real encoder, frame review, independent approval, retention and exports. Optional
synthetic inputs remain inside the real workflow. No recognition, live aircraft
control, public upload service or anonymity decision was added.

The application download excludes PyAV/av.libs/FFmpeg codecs. Before opening a
profile, explicit native first-run Install/Cancel shows the exact official PyPI
wheel, bytes, SHA256, ABI, provider and upstream terms. After installation,
application/worker imports verify its original wheel and complete extracted tree
offline. No pip/source build, downloaded installer hook or arbitrary URL is used.
This is a technical distribution design, not legal or patent clearance. See
[dependency scope](../MULTIMEDIA_DISTRIBUTION.md).

## Defects and negative evidence

- A frozen worker could not use `python -m workbench.worker`. Its fixed native
  entry accepts exactly one service-owned job directory, not arbitrary modules.
- Inherited native-owner stdin could leave real media work blocked until owner
  Quit. `subprocess.DEVNULL` isolates the worker. A real parent/child pipe test
  proves child EOF and preservation of the owner's command; restoring the old
  behavior made that test fail. Original failed native/API observations remain
  private evidence, not silently relabeled successes.
- A pending initial user request could race a newly typed login. Controls now
  stay disabled during that operation. Actual delayed-response journeys failed
  against the old UI and passed with the fix.
- Real Tcl notice tests intermittently emitted blank TclError under full-suite
  descriptor capture; the exact cause is unproven. All original 13 cases now run
  once in a fresh bounded interpreter with capture=sys, required by both ordinary
  pytest and packaging. Zero exit/all 13distinct IDs/no skips/errors/failures are
  required. This does not suppress production notice errors or lower coverage.
- Windows ZIP readers normalize backslashes. The new actual malformed-wheel
  fixture caught that detail; extraction checks original stored names as well as
  the normalized name, preserving the same refusal across operating systems.
- Independent review found that the initial offline verifier traversed unknown
  directory trees before comparing its file inventory; an extra empty directory
  was also ignored. The verifier now derives the exact expected files/parents,
  counts visited entries and refuses extras before recursion, including actual
  site/member junctions on Windows. Both independent unknown-tree regressions
  failed against the exact old `27339048230587550b5fb39a44714645d9711bea`
  implementation and passed after the fix. Unexpected contents remain preserved.
- Earlier combined-codec packaging passed media tests but its upstream
  source/license recipe completeness was not established. That candidate and
  investigation are retained privately as held historical development evidence.
  They are not the codec payload in this application download.

The first codec-free Windows candidate passed actual freeze, safe extraction,
inner/outer identity and frozen Tcl/Tk runtime checks with final Python 3.14.10,
Tcl 9.0.4 and Tk 9.0.4. Build guards inspected the actual embedded PYZ module inventory
and file tree for PyAV/codec payloads. The extracted executable explicitly received
INSTALL consent, downloaded the official 28,150,949-byte cp312-abi3 Windows wheel,
verified SHA256 `3ce5a1d7b916d13c16ac58f1756f0fee4af2d53f02bc1403e18550b50d375a22`
and used its separate synthetic dependency store offline afterward. No real user
profile, prior listener, developer-runtime PATH or source service was used.

The actual browser imported synthetic video, prepared eight moving-mask envelopes
and one static plate mask, processed revision 1, confirmed export refusal before
independent review, switched reviewer and downloaded the approved MP4/receipt.
A separate PyAV decoder checked all 40 frames at 640×360 / 10 fps, one video-only stream,
exact receipt/download hash, every requested moving/plate pixel below the dark
threshold and retained unmasked context. Those checks do not establish anonymity.
Mobile layout, automated accessibility, no unexpected external browser requests
and normal owner Quit/exit 0 without forced cleanup also passed. Two actual PNGs
were individually inspected: decoded frame review and approved controlled export.

## Startup cost and preserved failure

The later Windows native job at source
`ee01a117c74be2f31e2c45cc369449c7e26e88ea` completed freezing/setup but exceeded
the existing 20-second owned-readiness deadline before a readiness marker arrived.
[Actual failed job](https://github.com/JasonStys/drone-video-privacy-studio/actions/runs/42972885172/job/130365212226).
Linux and macOS passed that revision; this does not turn Windows into a pass.
The original runner did not print its saved child startup log, so the exact hosted
cause is unproven. Bounded sanitized phase/failure output now makes later failures
inspectable without uploading profiles, media or binary artifacts.

Independent local measurement of the same real pinned wheel/tree found an
avoidable allocation cost: each tiny file requested the entire 128 MiB member
cap, and ordinary startup performed the complete verification twice. Three
before samples were 7.525, 7.409 and 7.530 seconds per walk. Reads now request only
the opened descriptor size plus one byte, preserving growth/truncation detection,
and a non-authorizing presence check only chooses setup; activation still checks
the exact complete tree once before import. Three local after samples were
0.559, 0.380 and 0.397 seconds per walk. This is a local method comparison, not
hosted timing or proof of the earlier timeout's cause. Independent real-descriptor
growth/allocation tests and tamper-no-import/no-download tests pass. The 20-second
readiness and all original browser/worker deadlines remain unchanged.

## Source tests and limits

Final full source validation passed **260 parent Python tests plus all 13 mandatory
isolated notice cases**, with **93.88% branch-aware package coverage** against the
unchanged 90% floor. One existing Windows symlink-capability skip is explicitly
reported; Linux and macOS must exercise that capability in CI. These include 55 new
real-wheel/Tk contracts and five codec-free bundle-inventory cases, plus the
codec-free shell/entry failure and actual notice-inventory regressions. Corrupt,
truncated, oversized or offline providers, wrong ABI/version/name, unsafe ZIP paths
and file types, RECORD/expansion failures, unknown-store preservation, installed
tamper, concurrent no-overwrite publication, Cancel without fetch, explicit Install
and visible failure without retries all have independent negative cases.

Seven pure TypeScript helpers retained 100% statement/function/branch/line coverage;
strict TypeScript and production Vite build passed. The original source browser
suite passed 24 journeys across Chromium, Firefox, WebKit and mobile WebKit (three
engines, four profiles), including real media and the login-race regression.

Native setup is an explicit first-install public dependency request; provider/TLS
availability and disk space can fail. Later verified use is offline. Unknown or
corrupt dependency stores are preserved/refused, never silently reset. Native
acceptance uses console consent and actual frozen browser interaction plus source
Tk controls; it does not claim manually clicking a frozen owner/setup window.
Archives are unsigned portable applications, not signed installers, OS-sandboxed
parsers, clean-machine installations or externally certified secure products.
Local OS owners/admins can access data. Full upstream codec rebuilding, bit-identical
codec reproduction, patent clearance and legal certification are not established.
