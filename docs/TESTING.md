# Test strategy

Highest risks are exporting pixels outside the intended mask interval, copying audio/private metadata, inheriting a stale approval, leaking another operator's original/notes and publishing partial native work. Tests prioritize these invariants over superficial snapshots. No production footage/accounts are used.

| Layer | Independent evidence / failure cases |
| --- | --- |
| Python contracts | Finite geometry, strict types/extras, empty/out-of-frame masks, inclusive frame ranges, <=32 masks, strict telemetry ordering/duplicates, drift/gaps/offset and absent position. |
| Real native codec | Generate MP4 through real native encoder; use a separate fixture with AAC audio/private tags. Decode actual output, verify only one video stream, marker absence, correct count/timestamps, requested pixels dark, unmasked region survives. Frames before/after a bounded mask must remain unmasked. Source and output compare is not a mock `success` boolean. |
| Media failure | Truncated/fake format, high fps, oversized decoded images, frame/input/output limits, irregular PTS, mask outside timeline, wrong output dimensions/timing/count, non-video streams and missed requested mask. |
| API/SQL integration | Actual ASGI requests, Argon2, SQLite and worker subprocess; owner/reviewer/admin scope, unauthenticated access, direct-ID probing, ranged media, no original/static-runtime route, minimal receipt leakage, source/media/plan hash tampering, immutable revision SQL, current-version CAS and review interleavings. |
| Auth/network | Hashed bearer storage, one-hour expiry/role recheck/revocation, no reflected credentials, exact Host/Origin, CSRF, content/size/body backpressure, persistent per-client attempt bounds, concurrent Argon2 bound and <=10 sessions. A real TCP Uvicorn regression verifies rotating forged forwarding headers cannot bypass the direct-client throttle. |
| Interruption/retention | Inject deadline/nonzero worker/missing-result/storage failures; no published record/scratch remains after ordinary failure. Expiry denies every endpoint. Explicit purge defaults dry-run, validates all paths and refuses unexpected content; confirmed isolated expired media and dependent rows are removed, audit remains. |
| TypeScript helpers | Geometry intent, inclusive boundary validity, time interpolation/offset/no extrapolation/gaps and exact-version approval presentation. 100% statement/function/branch/line coverage required for pure helper module; this is not a claim of 100% UI coverage. |
| Real browser journeys | Actual Python/SQLite/native service in Chromium, Firefox, WebKit and iPhone WebKit. Real synthetic creation, upload, decoded video/canvas masked-pixel check, annotation, telemetry, reviewer switch, actual downloads/receipt content, invalidation by next revision, escaping/XSS title, frame seek, late-response logout, responsive layout and axe WCAG automated checks. No mocked backend. The race test delays an actual fetched response; it does not synthesize trusted media/results. |
| Supply chain/static/docs | Full hash locks, immutable action refs, no private binary/runtime source, live pip audit, complete live OSV npm inventory with zero findings, strict TS/Ruff/Prettier, CodeQL Python and TypeScript, generated file/function/parameter/variable maps reject drift. |

## Gates and reproducibility

Required Python coverage is >=90% including package branches, not tests-only coverage; no coverage exclusions for safety code. TypeScript helper thresholds are 100%. Browser retries are **zero**. Core matrix includes Ubuntu/Python 3.12 and 3.14, Windows/3.14 and macOS/3.14. Tests use private random disposable accounts and unique directories. Symlink creation is capability-dependent: a Windows account without symlink privilege skips that one test explicitly; Linux/macOS CI exercises it. It is not turned into a fake pass.

Run the README commands. For local cached Playwright browsers, an explicit `PLAYWRIGHT_BROWSERS_PATH` may select an already installed matching vendor build; CI installs matching pinned browser versions. Test launcher chooses the local venv if it exists, otherwise the actual `setup-python` interpreter—no nonexistent CI venv assumption. Every failed test is diagnosed before rerun; no error suppression, `continue-on-error`, advisory ignores, rerun-to-green policy or gate lowering.

## What the tests do not establish

Each browser engine now receives its own fresh real service/database through `tools/browser_checks.mjs`. Sharing one 20-login/minute direct-client budget across all engines previously correctly triggered the security limiter after repeated role-switch tests; isolated suites avoid test-environment interference without changing production limits, injecting auth tokens, waiting/retrying failures or weakening the real TCP throttle test. All four engines still run the same complete journey. Continuous H.264 pixels are checked where decoding works; codec-limited Windows WebKit checks actual worker-rendered PNG pixels. Every engine also explicitly exercises real frame-20 PNG retrieval. No mocked media or skip substitutes for inspection.

No detector has been trained/validated; no real-person recognition accuracy, formal privacy proof, fuzzing of every FFmpeg codec, hardened public upload containment, external penetration test, native mobile installer certification, legal permission, secure erasure, real-time flight performance or complete accessibility compliance is claimed. Automated axe checks are one layer; manual keyboard/visual inspection and contextual privacy review remain necessary. Timed performance measurements are informational and hardware-specific, not comparisons fabricated from asymptotic complexity.
