        Help · how this works and what it does not do
        
    A review tool, not an anonymity certificate
    
        
    
          Operators import authorized short clips, add time-bounded rectangular
          masks and private notes, then process a revision. Reviewers inspect
          the entire processed video and record approval or rejection. Only the
          current approved revision can be exported. Reprocessing invalidates
          approval.
        
    
        
    
          All exports are new video-only MP4s. Source audio, user-origin
          metadata, subtitles, attachments, telemetry and private notes are not
          copied. Technical MP4/encoder metadata remains. Visible scenery,
          uniforms, reflections, shapes and voices in external material can
          still identify people; this application has no automatic face/plate
          detector or identity search.
        
    
        
    
          Accounts, originals and processing stay in the local workspace.
          Reviewers and admins are authorized organizational readers; the
          computer owner can read disk files. This is not encrypted multi-tenant
          cloud hosting, a police/medical evidence system, a live drone feed or
          a legal compliance certification.
        
    
        
    
          Expired clips cannot be accessed or exported. The OS owner can purge
          expired app-owned media using the documented CLI. Backups/downloads
          are independent copies and require their own retention policy. See the
          repository’s user guide and security model for limits.
