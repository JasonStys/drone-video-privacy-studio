# Security

This release is for trusted local staff and bounded authorized clips only. Do not expose it to public uploads or assume that native media parsing is OS-sandboxed. Read [the security model](docs/SECURITY_MODEL.md) and [operations guide](docs/OPERATIONS.md).

For a suspected vulnerability, contact [Jason Stys on LinkedIn](https://www.linkedin.com/in/jason-stys-31b30b351/) to arrange private disclosure, or use GitHub private vulnerability reporting if enabled. Do not post sensitive footage, passwords, tokens or database/runtime files in public issues. Provide a minimal synthetic reproduction, exact commit/platform and observed impact; do not claim a speculative scanner result is a verified exploit.

Only the current main source/locked dependencies are maintained. No external audit, legal compliance certification or guaranteed response SLA is claimed.
